# TUI 设计规范（Phase 0 目标稿）

本文档定义 TUI 的目标设计语言。Phase 0 只写规范；Phase 1–5 分批迁移。
规范中的“必须”表示后续契约脚本会检查，“建议”表示评审约定。

## 1. 设计语言一句话

**骨架统一、页面语法统一、组件变体有限。**

- 骨架：页眉、仪表盘、面包屑、主体、页脚，由外壳强制。
- 页面语法：摘要 → 分区 → 操作；标题只在面包屑，正文不再重复。
- 组件变体：菜单/表单一种，数据表一种，报告页一种。

## 2. 布局

### 2.1 固定框架

```
项目名
（空行）
┌── 仪表盘 ──────────────────────────────┐
│ 当前配置                                │
│ 站点 ...                                │
│ 任务总览 ...                            │
└─────────────────────────────────────────┘
（空行）
面包屑
────────────────────────────────────────
（空行）
主体
（可选）✔ 临时提示
页脚：本页按键 · 全局按键
```

- 页眉高度固定 2 行。
- 仪表盘在终端过矮时从下往上删配置项，站点永远保留。
- 页脚固定在最后一行；终端过窄时换成紧凑写法。

### 2.2 页面骨架

每个页面必须是以下顺序之一：

1. `summary`（可选）→ `sections` → `actions`。
2. `summary` → `body`（自定义行）→ `actions`。
3. 纯信息页：`message` 行 + 空行，不含 actions。

规则：

- **面包屑是页面标题**；正文不再重复画页面名。
- 实体名（模型名、收藏集名、版本名）可以作为正文第一行，使用 bold，**不再加第二条横线**。
- 正文最多一条横线：面包屑下方那条。`pages.heading()` 只保留 bold 文本，不再画短横线。
- 分区标题统一为 `── 标题 ─────────`，使用 dim 色，占满可用宽度。
- 摘要使用 `label + 两空格 + value`，label 列按最长标签对齐，value 超宽裁剪。
- 操作区永远在最后，危险操作使用 `danger` 语义色。
- 状态行固定在主体最后一行，与页脚之间不留空行。

### 2.3 缩进

- 框架左边距：宽度 ≥ 54 时为 2 列，否则 1 列。
- 菜单/表单行：`光标 + 空格 + 标签`，标签从第 2 列开始。
- 报告行：`两个空格 + 标签`；选中时用 `▸ ` 替换前两个空格，标签列不动。
- 分区标题从第 0 列开始（相对主体）。
- 摘要从第 2 列开始。

## 3. 列表

只允许两种变体。

### 3.1 MenuList / FormList

用于菜单、确认、设置、版本动作、任务列表。

```
▸ 下载                  下载模型或收藏集
  本地模型管理          按模型管理本地文件
```

- 光标：`▸`，非选中行用空格占位。
- 选中行标签加粗。
- 首尾循环。
- 翻页 10 行。
- `Home/End` 到首尾。
- 数字键只移动光标，不直接执行；执行统一用 Enter。

### 3.2 DataTable

用于选择器、下载计划、多选列表。

```
▸ [×]  1  模型名称          类型 · 底模 · 状态        1.2 GB
  [ ]  2  另一个模型        ...                       800 MB
```

- 整行反显表示光标。
- 第二列固定为勾选框。
- 列：光标、勾选、序号、名称、说明、大小。
- 夹紧不循环，避免长列表从末行跳回首行。
- 翻页使用自身 pageSize。
- 搜索、过滤、排序、`?` 帮助由选择器统一提供。

### 3.3 禁止

- 新增第三套列表渲染。
- 页面自己实现 `cursor <= 0 ? length - 1 : cursor - 1`。
- 页面自己计算名称列、大小列、详情列宽度。

## 4. 颜色与字符

### 4.1 语义色

| 令牌 | 用途 | 当前映射 |
|---|---|---|
| `color.text` | 普通文本 | 无样式 |
| `color.muted` | 次要说明、标签、边框 | `dim` |
| `color.accent` | 焦点、进度、信息 | `cyan` |
| `color.success` | 成功、登录态 | `green` |
| `color.warning` | 警告、排队、取消、危险确认 | `yellow` |
| `color.danger` | 失败、错误、危险操作 | `red` |
| `color.cursor` | 列表光标 | `cyan` |
| `color.selection` | 数据表选中行 | `reverse` |
| `color.progress` | 进度条 | `cyan` |
| `color.border` | 方框边框 | `dim` |

任务状态映射（保持现有视觉）：

- `running` → `success`
- `done` → `accent`
- `queued` / `cancelled` → `warning`
- `failed` → `danger`

禁止：

- 流程层直接使用 `colors.red/green/...`；必须使用语义令牌。
- 新增 `colors.blue` / `colors.magenta` 的使用。

### 4.2 字符

所有展示字符必须来自 `layout.glyphs()` / `tokens.glyph`：

- 光标 `▸`，ASCII `>`
- 勾选 `[×]` / `[ ]`
- 分隔 ` | `（TUI 内容、页脚提示与 TUI 硬编码统一；CLI/Web 不改）
- 项目符号 `·`（只用于列表项目，不充当分隔符）
- 失败 `!`
- 占位 `--`
- 方框与进度条随字符集降级

禁止在流程里写 `'·'`、`'!'`、`'--'`。

## 5. 键盘与页脚

### 5.1 全局键

- `↑↓`：移动；不再提供 `j/k`。
- `Home/End`：首尾。
- `PgUp/PgDn`：翻页。
- `Enter`：执行当前焦点动作，不是全局确认。
- `Esc`：返回上一层或关闭覆盖层；创建任务页按 Esc 返回主菜单，不取消任务。
- `Tab`：页面内的区域焦点切换；不再是任务视图开关。
- `Ctrl+M`：打开/关闭任务视图（全局覆盖层）。
- `Ctrl+L`：打开会话日志（全局覆盖层，标题为“日志”）。
- `Ctrl+C`：退出；有任务运行时先请求取消。
- `?`：帮助；所有页面都应可用，并在帮助页列出上述全局键。

日志页只接受 `Esc` 关闭；单任务日志已移除。任务视图与日志页都不挂在主菜单下，
它们从任何页面都能用快捷键打开，属于全局覆盖层。

### 5.2 页脚

- 恰好一行。
- 只列这一页真的有动作的键。
- 不展示 `↑↓` / `j/k` 等通用移动键。
- 不自动附加全局键；`Tab`、`Ctrl+M`、`Ctrl+L` 是否出现由页面决定。
- `?` 作为动作键保留，用于查看全量键位（包括全局键）。
- 终端过窄时使用 `tui.hint.compact`，不截断词。
- `footerHints()` 不接受多行；页面返回多行会被丢弃。
- 下载计划页/确认页的页脚示例：
  `Tab 切换区域 | Enter 执行 | Esc 返回 | ? 帮助`。

### 5.3 面包屑与步骤

- 路径表示层级：`主菜单 › 下载 › 下载模型`。
- 步骤表示当前流程进度：`[选择 | 确认 | 回执]`。
- 完整形式：`主菜单 › 下载 › 下载模型  [选择 | 确认 | 回执]`。
- 当前步骤高亮，已完成步骤 dim，未开始步骤更暗。
- 窄屏退化为 `步骤 2/3 确认`，不截断步骤词。
- 临时操作菜单使用 `crumb: false`，不进入路径或步骤。
- 正文标题与父级同名时，不再 push 第二段；相邻两段不得相同。
- 任务视图与日志页是全局覆盖层，不进入主菜单路径；日志页标题为 `日志`。
- `Esc` 返回由流程定义，不由 `screen` 盲弹；创建任务页按 `Esc` 返回主菜单，任务继续运行。

## 6. 反馈

| 场景 | 方式 |
|---|---|
| 动作成功/失败 | `toast`，5 秒消失，同时写日志 |
| 没有数据但需要解释 | `emptyPage`，例如“还没有收藏集快照，先去下载一次” |
| 被动信息、过程细节 | `log`，按 `Ctrl+L` 查看 |
| 超过数秒的等待 | `withSpinner`，阶段写进面包屑 |
| 不可恢复错误 | `toast` 红色 + `log` + 退出码 |

禁止：空状态只写一行日志；错误只写日志不提示；加载时屏幕没有任何变化。

## 7. 格式

统一使用 `tokens.format`：

| 函数 | 输出 |
|---|---|
| `format.date` | `YYYY-MM-DD` |
| `format.dateTime` | `YYYY-MM-DD HH:mm` |
| `format.dateTimeFull` | `YYYY-MM-DD HH:mm:ss` |
| `format.bytes` | `1.2 GB` |
| `format.duration` | `01:23` |
| `format.count` | 数字转字符串 |

未知值统一使用 `t('common.unknown')` 或 `tokens.glyph.placeholder`，不再混用 `-`、`--`、空字符串。

## 8. 响应式

断点：

- `narrow`：宽度 < 54，去掉边框、说明、次要列，页脚用紧凑写法。
- `compact`：54 ≤ 宽度 < 72，保留主要列，去掉次要列。
- `wide`：宽度 ≥ 72，完整布局。

降级顺序：

1. 去掉次要列（日期、路径、状态尾注）。
2. 去掉描述文字。
3. 去掉边框。
4. 页脚换紧凑写法。
5. 列表只保留名称与光标。

禁止每个页面自定义 `0.4`、`width - 30`、`64` 这类局部阈值；统一从 `tokens.breakpoint` 取。

## 9. 设计约束矩阵

| 方面 | 现状 | 目标 | 负责 Phase |
|---|---|---|---|
| 固定框架 | 强制 | 保持 | — |
| 页脚单行 | 强制 | 保持 | — |
| 页脚内容 | 混合全局/本页 | 只列本页动作键 | Phase 5 |
| 全局键 | `Tab`/`L` | `Ctrl+M`/`Ctrl+L` | Phase 3/5 |
| 页面标题/横线 | 多套 | 一套 | Phase 2 |
| 列表语法 | 4–6 套 | 2 种 | Phase 3 |
| 配色语义 | 调色板 | 语义令牌 | Phase 1 |
| 日期格式 | 4 种 | 1 套 | Phase 1 |
| 分隔符 | `·` / `\|` 混用 | TUI 内统一为 `\|` | Phase 1.5 |
| 空/加载/错误 | 4 种 | 1 套 | Phase 5 |
| `?` 帮助 | 部分 | 全部 | Phase 5 |
| 面包屑层级 | 有重复 | 无重复 | Phase 5 |
| 流程步骤 | 无 | `选择 \| 确认 \| 回执` | Phase 5 |
| 日志页 | 全局 `L` | `Ctrl+L` + 独立标题 `日志` | Phase 4/5 |
| 响应式断点 | 分散 | 3 档 | Phase 1/2 |
| 双路径等价 | 部分分叉 | 文档化 + 共享模型 | Phase 6 |

## 10. 评审清单

新增或修改页面时必须回答：

- 页面骨架是否用了 `page`（或 `report`/`picker`）？
- 是否只有一条横线？
- 是否使用了语义色和字符令牌？
- 分隔符是否统一为 ` | `？
- 是否只有一种列表变体？
- 页脚是否只有一行，且只列本页动作键？
- `?` 是否可用，并能查到 `Ctrl+M`/`Ctrl+L`/`Ctrl+C`？
- 流程步骤是否只在 `选择 | 确认 | 回执` 三态内？
- 日志页是否从 `Ctrl+L` 打开、标题为 `日志`、只接受 `Esc` 返回？
- 空状态、加载、错误是否走了统一反馈？
- 日期是否走了 `format`？
- 54×12 终端下是否不越界？
- 是否新增了 `screen.isActive()` 或直接终端写入？
